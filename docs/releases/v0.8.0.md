## Nouveautés

- **Pièces jointes** : joins des fichiers avec le trombone, en les glissant dans la conversation ou en les collant (10 par message, 25 Mo chacun par défaut). Les images s'affichent en vignettes et s'ouvrent dans une visionneuse (flèches pour passer d'une image à l'autre, Échap pour fermer) ; les autres fichiers ont leur carte avec un bouton Télécharger.
- **Aperçus de liens** : un lien affiche une carte avec le site, le titre, la description et l'image. L'auteur peut la retirer, et `<lien>` entre chevrons n'en crée pas.

## Pour les hébergeurs

- Les pièces jointes sont stockées dans `KRAKEN_DATA_DIR`, comme les photos de profil : sauvegarde ce dossier (ou le volume Docker `data`) avec la base.
- `KRAKEN_MAX_UPLOAD_MB` règle la taille maximale d'un fichier (25 par défaut).
- Pour les aperçus, le serveur va lui-même chercher les pages des liens postés, en refusant toute adresse de ton réseau local. `KRAKEN_LINK_PREVIEWS=0` les désactive.
