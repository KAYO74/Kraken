## Nouveautés

- **Photo de profil** : dans Réglages › Compte, choisis une image, recadre-la et elle s'affiche partout, chez tout le monde. « Retirer » revient aux initiales.
- **Groupes** : un panneau « Membres du groupe » montre la couronne du propriétaire, qui peut retirer quelqu'un du groupe.
- **Messages privés** : une croix ferme un MP de ta liste ; il revient au prochain message.
- **Correctifs** : un compte en cours de suppression n'apparaît plus dans les MP, les groupes ni les amis ; le message d'erreur du nom de serveur indique la vraie règle (2 à 100 caractères).

## Pour les hébergeurs

Les photos de profil sont stockées dans `KRAKEN_DATA_DIR` (par défaut `./data`). Avec Docker, le `docker-compose.yml` monte un volume `data` sur `/var/lib/kraken` : récupère le nouveau `docker-compose.yml` avant de relancer, et pense à sauvegarder ce volume avec la base.
